The rules it cannot break

  • Every claim is checked against a committed receipt. A card pins one JSON receipt by repo, full commit and sha256; every number in the post must be a named field of it; a number from a claim that failed is refused; no hype, no prices, no economy talk.
  • Nothing leaves without Simon's approval of the exact words. The approval names the post and the sha256 of its text — change one character and it no longer counts. A rehearsal approval can only ever authorise a dry run.
  • Replies only when summoned. Someone @mentions us, we answer once, opt-outs honoured. This is also exactly where X draws its own line for automation.
  • Hard daily cap (4) — a voice, not a firehose.
  • No near-duplicates — shingle-overlap against everything ever posted; ≥0.6 is refused.
  • Dry-run by default. Without the owner's keys and an explicit switch, nothing leaves the machine — and this page shows the rehearsals anyway.

Questions people ask first

Does the near-duplicate check really work? It refused one of today's drafts: the credit pattern book's post overlapped the churn pattern book's at 0.643 (three-word shingles; 0.6 or more is refused), so it never reached the queue — the two posts said nearly the same thing. X refuses near-identical posts too.

Where are the X keys kept? In the environment of the machine that runs the voice — four variables the owner sets himself. The code reads them only to sign the request to X; it never writes them to a file, a log or this page (measured: claim V6 above).

What about something urgent? It goes through the same queue: drafted, checked, and out the moment the owner approves those words. There is deliberately no way to post without him.

Words used here. witness: the company's mutation gate — it breaks code on purpose to prove the tests would notice. receipt: a JSON file of measured results, committed to a public repo. sealed claims: what a piece of work must achieve, committed before the code that measures it — so the bar cannot move after the fact; each is then marked held or FAILED, and failures stay.
